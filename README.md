# Консилиум

Система бесед, где над вопросом работают несколько моделей: Claude, Kimi, Qwen. Есть черновики, критик, дебаты и итоговый разбор.

- **Пульт:** https://claude.ai/artifact/JtbDavitxLLq12xCLXEeAt. Там выбираешь режим, модели и глубину, задаёшь вопрос и жмёшь «Отправить», потом пишешь Claude в чат «го».
- **Режимы:** `/deep` (глубоко), `/debate` (дебаты), `/psych` (психолог). Лежат в `.claude/skills/`.
- **Как работает Claude:** описано в `CLAUDE.md`.

## Браузер

В репозитории подключён [Playwright MCP](https://github.com/microsoft/playwright-mcp), опенсорсный браузер для агентов от Microsoft (`.mcp.json`). Claude открывает настоящее окно Chrome, ходит по сайтам и читает страницы, а ты видишь, что он делает.

Запускать лучше на своём компьютере: маркетплейсы видят обычного пользователя с домашним IP и не показывают капчу. Нужен Node.js. Открой эту папку в Claude Code (десктоп-приложение или `claude` в терминале) и разреши MCP-сервер `browser`, когда он спросит.
